# Sparkle Quest 🦄

A magical unicorn adventure game for kids — built with HTML, CSS, and vanilla JavaScript.

**[Play Now →](https://vipin-mohan.github.io/agent-lab/sparkle-quest)**

> ⏱ Single HTML file hosted on GitHub Pages — loads instantly.

---

## What It Is

Sparkle Quest is a browser-based top-down adventure game where you guide a rainbow unicorn through three magical worlds — collecting stars and gems, dodging storm clouds, and finding the Golden Horn to complete each level.

Built as a father-daughter project to make learning to build things fun.

---

## How to Play

- **Move** — Arrow keys on desktop, D-pad on mobile (touch supported)
- **Collect** ⭐ stars (+10 pts) and 💎 gems (+25 pts)
- **Avoid** ⚡ storm clouds — you have 3 lives
- **Find** the Golden Horn to complete each level
- **Three levels:** Rainbow Meadow → Crystal Caves → Sky Kingdom

---

## Tech Stack

- **Game engine** — Vanilla JavaScript with Canvas 2D API
- **Rendering** — `requestAnimationFrame` game loop, 800×600 logical resolution
- **Audio** — Web Audio API (all sounds generated in code, no audio files)
- **Mobile** — Touch D-pad overlay, `viewport-fit=cover`, iOS safe area support
- **Hosting** — GitHub Pages (single HTML file, zero dependencies)

---

## Running Locally

No build tools or server needed. Just:

```bash
git clone https://github.com/vipin-mohan/agent-lab.git
cd agent-lab/sparkle-quest
open index.html
```

---

## Deploying to GitHub Pages

1. Push `index.html` to a public GitHub repo.
2. Go to **Settings → Pages** and set the source to the `main` branch.
3. Your shareable link: `https://[your-username].github.io/[repo-name]`
